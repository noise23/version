Dependencies
------------
Libraries you need to download separately and build:

                default path               download
libevent        \libevent-2.1.12-mgw       https://libevent.org/
Berkeley DB     \db-4.8.30.NC-mgw          http://www.oracle.com/technology/software/products/berkeley-db/index.html
Boost           \boost-1.47.0-mgw          http://www.boost.org/users/download/
miniupnpc       \miniupnpc-1.6-mgw         http://miniupnp.tuxfamily.org/files/

Their licenses:
libevent       3-clause BSD license
Berkeley DB    New BSD license with additional requirement that linked software must be free open source
Boost          MIT-like license
miniupnpc      New (3-clause) BSD license

Versions used in this release:
libevent     2.1.12
Berkeley DB  4.8.30.NC
Boost        1.47.0
miniupnpc    1.6

Note: OpenSSL is not used - secp256k1 (bundled) provides EC signing/verification,
and SHA/RIPEMD/AES are in-tree implementations. Randomness comes from
BCryptGenRandom, not OpenSSL's RNG.

Berkeley DB
-----------
MSYS shell:
cd /c/db-4.8.30.NC-mgw/build_unix
sh ../dist/configure --enable-mingw --enable-cxx
make

Boost
-----
DOS prompt:
downloaded boost jam 3.1.18
cd \boost-1.47.0-mgw
bjam toolset=gcc --build-type=complete stage

MiniUPnPc
---------
UPnP support is optional, make with USE_UPNP= to disable it.

MSYS shell:
cd /c/miniupnpc-1.6-mgw
make -f Makefile.mingw
mkdir miniupnpc
cp *.h miniupnpc/

Version
-------
DOS prompt:
cd \version\src
mingw32-make -f makefile.mingw
strip versiond.exe
